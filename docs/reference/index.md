## Reference rules

These pages are deliberately secret-safe and avoid volatile private IPs and credentials. Use the local dashboard, Pi-hole records, UniFi, and Proxmox inventory for current values. When a service is added or retired, update its catalog entry, monitoring, proxy route, backup note, and runbook together.
